# AutoLink Business Dashboard

Dashboard เชิงเล่าเรื่องสำหรับ AutoLink แพลตฟอร์มค้นหาและจำหน่ายอะไหล่รถยนต์ด้วย AI

## Story
ลูกค้าซื้ออะไหล่อะไรมากที่สุด → ช่องทางไหนสร้างยอดขาย → ลูกค้ากลุ่มไหนมีมูลค่าสูง → AutoLink ควรบริหาร Stock และใช้ AI อย่างไร

## Key Results
- ยอดขายสุทธิ: ฿6,996,142.50
- Orders: 1,800
- Customers: 249
- Units Sold: 3,673
- Average Order Value: ฿3,886.75
